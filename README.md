# Sales Forecast

Информационная система прогнозирования продаж с применением методов интеллектуального анализа данных.

## Возможности

- Загрузка и предобработка данных о продажах (CSV)
- Разведочный анализ данных (EDA) с интерактивными графиками
- Прогнозирование ежедневной выручки тремя методами ИАД:
  - **Random Forest** — ансамбль деревьев решений (бэггинг)
  - **LightGBM** — градиентный бустинг с leaf-wise ростом
  - **XGBoost** — градиентный бустинг с level-wise ростом
- Фильтрация по категории товара и точке продаж
- Оценка качества прогноза по метрикам **MAE**, **RMSE**, **MAPE**
- Сравнение моделей на одной оси
- Доверительные интервалы прогноза (±1.96σ)
- Текстовый вывод по прогнозу: тенденция, среднесуточные/суммарные продажи, пик и минимум
- Сохранение и просмотр истории прогнозов (SQLite)
- Экспорт результатов в CSV

## Структура

```
sales_forecast/
├── app.py            — Streamlit-интерфейс (4 страницы)
├── data_loader.py    — загрузка и агрегация данных
├── eda.py            — графики разведочного анализа (Plotly)
├── models.py         — три модели прогнозирования + сравнение
├── database.py       — SQLite: история прогнозов
├── requirements.txt  — зависимости
└── dataset/          — пример исходных данных
```

## Запуск

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## Требования к данным

CSV-файл с колонками:

| Колонка | Тип | Назначение |
|---|---|---|
| `invoice_date` | дата | Дата продажи (формат `ДД/ММ/ГГГГ`) — обязательно |
| `price` | число | Цена за единицу — обязательно |
| `quantity` | число | Количество единиц — обязательно |
| `category` | текст | Категория товара |
| `shopping_mall` | текст | Точка продаж |
| `payment_method` | текст | Способ оплаты |

Минимум **60 дней** истории для построения прогноза.
